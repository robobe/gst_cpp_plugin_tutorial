# Capstone Project Requirements

## Goal

Build a final GStreamer tutorial project that combines the concepts from the
earlier examples:

- a custom video source plugin
- a custom OpenCV filter plugin
- GObject properties
- custom buffer metadata
- a split pipeline
- a Python application that runs the pipeline and reads metadata

The final demo should generate video with a moving red box, detect that red box,
display the video, and print the detected bounding box from Python.

## Final Pipeline

The final pipeline should have this shape:

```text
moving red-box source
-> red detection filter
-> tee

tee branch 1:
queue -> videoconvert -> autovideosink

tee branch 2:
queue -> appsink -> Python prints bounding box metadata
```

Example conceptual pipeline:

```text
colorboxsrc ! reddetect low-h=0 high-h=10 ! tee name=t \
    t. ! queue ! videoconvert ! autovideosink \
    t. ! queue ! appsink name=metadata_sink
```

The exact element names can change during implementation, but the behavior must
match this pipeline.

## Required Components

The capstone must include:

- A Python GStreamer application that builds and runs the pipeline.
- A source plugin that generates raw video frames.
- A filter plugin that detects the red object using OpenCV HSV thresholding.
- Custom metadata that carries the detection bounding box downstream.
- A video branch that displays frames using `autovideosink`.
- A metadata branch that ends in `appsink`.
- Python code that reads samples from `appsink` and prints metadata to stdout.

## Plugin Requirements

### Moving Red-Box Source

The source plugin must:

- Generate raw video frames continuously.
- Draw a red box into each frame.
- Move the red box over time so detection changes from frame to frame.
- Set valid `PTS` and `DURATION` on every buffer.
- Use fixed beginner-friendly caps:

```text
video/x-raw,format=RGB,width=320,height=240,framerate=30/1
```

The source should be named `colorboxsrc` and should be based on the same idea as
`simplevideosrc`.

The box color must be configurable with RGB properties:

- `box-red`: integer `0-255`, default `255`
- `box-green`: integer `0-255`, default `0`
- `box-blue`: integer `0-255`, default `0`

The default box color is red.

### Red Detection Filter

The filter plugin must:

- Receive raw RGB video buffers.
- Map each `GstBuffer` safely with `GstVideoFrame`.
- Wrap the mapped memory with `cv::Mat`.
- Convert RGB to HSV using OpenCV.
- Threshold the image to find red pixels.
- Compute a bounding box around the detected red region.
- Attach custom metadata to the same buffer.
- Forward the buffer downstream.

The filter should expose HSV threshold properties so the user can tune red
detection from a pipeline:

- `low-h`
- `low-s`
- `low-v`
- `high-h`
- `high-s`
- `high-v`

Default values should detect the red box generated by the source plugin.

## Python Application Requirements

The Python application must:

- Use GStreamer Python bindings.
- Build the full pipeline programmatically or with `Gst.parse_launch`.
- Set `GST_PLUGIN_PATH` or document that it must point at `build`.
- Start the pipeline.
- Pull samples from `appsink`.
- Read the bounding-box metadata from each sample buffer.
- Print detection output to stdout.
- Stop cleanly on `EOS` or error.

Example stdout shape:

```text
frame=42 found=true x=120 y=80 width=40 height=40
```

## Metadata Requirements

The detection metadata must describe one bounding box.

Required fields:

- `found`: boolean
- `x`: integer
- `y`: integer
- `width`: integer
- `height`: integer

If no red object is detected:

- `found` must be `false`
- `x`, `y`, `width`, and `height` should be `0`

The first implementation should use the simple custom metadata approach already
introduced in this tutorial. If Python cannot read that metadata cleanly, the
implementation should switch to a metadata representation that is accessible
from Python, while keeping the same field names and behavior.

## Acceptance Criteria

The capstone is complete when:

- `cmake --build build` succeeds.
- `gst-inspect-1.0` can inspect each custom plugin.
- A command-line pipeline displays the generated moving red box.
- The Python application starts the full split pipeline.
- The video branch displays frames using `autovideosink`.
- The metadata branch delivers samples to Python through `appsink`.
- Python prints bounding-box values while video is running.
- Changing HSV threshold properties changes detection behavior.
- When detection fails, metadata still exists and reports `found=false`.

## Suggested Milestones

1. Create the moving red-box source plugin.
2. Verify the source with `gst-launch-1.0 colorboxsrc ! videoconvert ! autovideosink`.
3. Create the OpenCV red detection filter.
4. Add HSV threshold properties to the detection filter.
5. Attach bounding-box metadata from the detection filter.
6. Verify metadata with a temporary metadata printer element or debug logging.
7. Build the `tee` pipeline with video and metadata branches.
8. Create the Python GStreamer runner.
9. Read `appsink` samples in Python and print bounding-box metadata.
10. Run the final demo and document the command.

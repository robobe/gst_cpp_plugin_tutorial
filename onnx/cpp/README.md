# ONNX Runtime C++ Examples

- [`minimal/`](minimal/) creates and runs the add-one teaching model.
- [`yolo/`](yolo/) runs the complete YOLOv8 pipeline on `assets/bus.jpg`.

The examples have separate source and CMake files. Both use the extracted ONNX
Runtime package at `onnx/cpp/onnxruntime-linux-x64-1.29.0`.
